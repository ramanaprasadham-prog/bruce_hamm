WordPress theme transferred from the Bruce Hamm static site.

== Installation ==

1. Upload `wordpress-theme/bruce-hamm.zip` in WordPress under Appearance → Themes → Add New → Upload Theme.
   If you prefer to zip it yourself, zip the `bruce-hamm` folder so `style.css` is at the top of that folder.
2. Activate Bruce Hamm.
3. Go to Settings → Permalinks and click Save Changes.
4. The theme creates Home, Biography, Gallery, Music, Videos, Events, Lessons, and Contact.
5. Add or edit concerts under Events in the WordPress admin.

The live pages keep the current design, photos, audio, search, and Formspree contact form.
