WordPress theme transferred from the Bruce Hamm static site.

== Installation ==

1. Upload `wordpress-theme/bruce-hamm.zip` in WordPress under Appearance → Themes → Add New → Upload Theme.
   If you prefer to zip it yourself, zip the `bruce-hamm` folder so `style.css` is at the top of that folder.
2. Activate Bruce Hamm.
3. Go to Settings → Permalinks and click Save Changes.
4. The theme creates Home, Biography, Gallery, Music, Videos, Events, Lessons, and Contact.
5. Add or edit concerts under Events in the WordPress admin.

== Editing the site (no PHP needed) ==

* Biography, Home and Lessons text: Pages → edit the page and change the text in the editor. Each biography section is a "Biography section" block; add more from the + button under Patterns.
* Photos, headings, albums, tracks (upload MP3s with "Choose audio file") and YouTube videos: Pages → edit the page and use the boxes under the text (the "Meta Boxes" panel at the bottom of the editor). Click a row to open it, drag to reorder.
* Concerts: Events in the left-hand menu. Concerts dated today or later show under Upcoming; older ones move to Past automatically.
* Contact form: Appearance → Customize → Contact Form (paste the Formspree form ID).
* Footer text: Appearance → Customize → Footer.

Until a page is saved, it shows the built-in default content, so the site looks the same as before.

The live pages keep the current design, photos, audio, search, and Formspree contact form.
